# Decisões ativas

- **Loja só vitrine; compra na Shopee/Mercado Livre (escolha da usuária, 23/11/2026).** Por quê: ela preferiu vender pelos marketplaces em vez de pagamento direto. Compra automática no marketplace foi descartada: não há API de comprador e robô na conta viola os termos; dropshipping também. Exige: botões por produto para os anúncios (nova aba), links validados por domínio. Proíbe: reintroduzir carrinho/checkout/pagamento sem pedido. Substitui a decisão do Mercado Pago Checkout Pro.
- **Prisma fixado na 6.19 (não 7/8).** Por quê: versões novas exigem driver adapter como dependência extra, fora da lista aprovada. Exige: não atualizar o Prisma sem aprovar o adapter.
- **Hospedagem no Railway em vez da Vercel.** Por quê: Vercel Hobby proíbe uso comercial e não guarda arquivos em disco; Railway (US$ 5) roda `next start` como servidor comum, com volume para `./uploads`, sem mudar código. Config (build `npm run build`, start `npm start`, variáveis) fica no painel do Railway, não em arquivo.
- **Banco trocado de SQLite local para Postgres hospedado (Neon), conectado via Storage da Vercel.** Por quê: a usuária quis mostrar o site pra outra pessoa em outro PC; SQLite é arquivo local e não funciona em serverless (Vercel). Mesmo banco serve dev local e produção. Exige: `DATABASE_URL`/`DATABASE_URL_UNPOOLED` em `.env` (Prisma CLI só lê esse arquivo, não `.env.local`); já injetadas na Vercel pela integração Neon.
- **`cacheComponents` desligado no `next.config.ts`.** Por quê: modelo de renderização clássico, mais simples para páginas com banco. Exige: `export const dynamic = "force-dynamic"` em páginas que leem o banco.
- **`build` não roda `prisma generate`.** Por quê: no Windows o dev server trava a DLL e o build falhava. Exige: gerar o client via `postinstall`/`npx prisma generate` com o dev parado.
- **Rastreio: a dona cola o código no pedido → status `enviado` → email automático pelo Resend (fetch, sem SDK).** Sem chave, o código fica salvo e o email não sai. Avisos para a dona (email/Telegram) seguem fora de escopo.
- **Imprimir pelo pedido: link `bambustudioopen://` para um download assinado e temporário do .3mf (um por produto).** Por quê: Bambu Studio é o programa da dona e baixa o arquivo sem cookie.
- **Voz da marca "próxima e caprichosa", produtos de decoração e casa.** Ver `PRODUCT.md`.
- **Catálogo trocado de peças fictícias para 7 produtos reais (ganchos, saboneteiras, suporte de lavadora, letreiro de Natal), em 2 categorias: Organização e Decoração sazonal.** As peças continuam sendo impressas em 3D pela dona; só o site não menciona isso. Exige: a vitrine não fala em "feito à mão"/"produzimos"/impressão 3D em nenhum lugar (nem no pedido personalizado); tudo é "pronta entrega". O arquivo de impressão (.3mf) é interno, só no admin. Fotos vêm de `public/produtos/<pasta>/main_images/*.jpg` (material do fornecedor/Shopee) — várias são banners com texto de marketing; por padrão só as imagens sem texto sobreposto vão pro seed (`images` de cada produto); exceção pedida pela dona: o suporte de lavadora usa as artes de anúncio com texto (`main_images/anuncio-*.webp`) e é o 1º da vitrine. `categoryId` é opcional no schema (coluna nova sem quebrar dados existentes), mas o seed sempre preenche. Estrutura de home/header (trilho de categorias, seções por categoria, banda de coleções) inspirada na casaquetem.com.br. Rota nova: `/categoria/[slug]`.
- **Logo trocada pela arte em `public/brand/` (ícone do vaso + "YUMI" + "Mix" cursivo).** Componente `src/components/Logo.tsx` (`LogoYumiMix`, `currentColor`) usado no cabeçalho, rodapé e admin; `src/app/icon.svg` é o favicon: círculo grafite com só o "Y" + raminho dourados (paths tirados de `yumi-mix-horizontal-dourado.svg`), sem fundo quadrado nem textos miúdos. Não reintroduzir o ícone quadrado antigo (`Marca`, removido de `Icones.tsx`).
- **Visual "padrão bem-feito": loja clara, cartões bem arredondados com sombra macia, botões em pílula, sem linhas divisórias; régua de capricho Apple Store / Allbirds.** Escolhido pela usuária (achou a galeria P&B quadrada e pouco convidativa), substituindo "A Galeria". Fonte Figtree via `next/font`, baixada no build. Exige: seguir `DESIGN.md`; nenhum outro webfont/CDN; animações só em CSS (GSAP não é dependência aprovada).
